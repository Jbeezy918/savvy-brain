# SavvyTech Master Command Hub

**One-click project scanner + dark dashboard for your local codebase.**

This tool scans your home folder, finds active project directories, categorizes them, and builds:

- `~/Master_Codebase/index.json` — structured data
- `~/Master_Codebase/index.html` — beautiful dark-mode dashboard

It then opens the dashboard in your browser automatically.

---

## Quick Start (macOS – recommended)

1. Copy the entire **SavvyTech_Master_Hub** folder to:
   ```
   ~/Desktop/Tools/SavvyTech_Master_Hub
   ```
   (or any location you prefer)

2. Double-click **`Run Master Hub.command`**

   - The first time macOS may warn you. Right-click the file → **Open** → confirm.
   - After that it will run with a double-click.

3. The Terminal window will show a summary of what it found, then your browser will open the dashboard.

---

## Alternative ways to run

```bash
cd ~/Desktop/Tools/SavvyTech_Master_Hub
python3 master_hub.py
```

Or make the command file executable once:

```bash
chmod +x "Run Master Hub.command"
```

| Home Automation & Local OS      | home, os, smart, scheduler, bambu, audio, print, 3d, scad, tinkercad, printer, automation |
| AI & Agent Systems              | agent, swarm, claw, ai, llm, lucy, joe, bot, mir, gpt, claude, grok, openai |

## Output location

Everything is written to:

```
~/Master_Codebase/
├── index.json
└── index.html
```

You can bookmark `index.html` or pin the Master_Codebase folder for quick access.

---

## Requirements

- Python 3.8+ (comes pre-installed on modern macOS)
- No extra packages needed – pure standard library

---

## Tips

- Re-run the tool anytime you create new project folders.
- The dashboard is pure HTML/CSS – no server required.
- If you want the tool itself to live inside Master_Codebase, just move the whole folder there.
