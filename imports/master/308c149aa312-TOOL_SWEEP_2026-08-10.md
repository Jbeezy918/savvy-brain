# Whole-machine tool sweep — 2026-08-10

Scope note up front: your home folder has 250+ top-level directories, most
looking like past experiments (heavy repetition of "savvy*", "agent*",
"govcon*", "youtube*" prefixes suggests a lot of rapid iteration over time).
A fully hand-verified check of every single one wasn't realistic in one
pass — I triaged broadly (found every real entry point: `start.command`,
`package.json`, git repos), then went deep on what actually looked real and
active. This is that list, not an exhaustive audit of all 250+.

## Real, active, worth knowing about

### Savvy Life (`~/Savvy_Life`) — biggest find
A genuinely substantial, well-built product — **not** the "launch-all-my-tools"
hub dashboard you described wanting (same name, different thing, worth not
confusing the two). This is a real SaaS MVP: a document-capture/invoicing
Progressive Web App for contractors and small service businesses — photograph
receipts/work orders/invoices, OCR + AI-extract the fields, organize by
customer/job, generate professional invoices. This looks like the actual
codebase behind **SnapToFill** (snaptofill.com, already flagged in memory as
"status unconfirmed" — it's very much not abandoned).

Real stack: Next.js 16, TypeScript, Postgres (Neon) + Drizzle ORM, Better
Auth, Cloudflare R2 storage, full test suite (Vitest + Playwright), CI.
**Active** — last commit 2026-08-03, recent commits completing auth, customer
management, and document capture modules. `npm run dev` should just work if
`.env.local` is populated (there's an `.env.example` to diff against).
